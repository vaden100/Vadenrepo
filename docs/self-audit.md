# Self-audit against the Website Build Specification

Audited 2026-10-06 against the current `main` of this branch. Status values:

- **Met**: implemented and, where it can be, verified by an automated test (named).
- **Partial**: implemented in part; the gap is stated.
- **Pending**: needs something that cannot be done in code (real devices, a person, a
  lawyer, production access) or belongs to a later SPEC phase. Owner/phase stated.
- **N/A**: does not apply to this product; reason stated (decisions in
  `docs/website-foundations.md` section 17).

Test names: `smoke`, `a11y`, `keyboard`, `forms`, `privacy`, `errors`, `lookup`,
`responsive`, `motion`, `visual`, `perf` = `apps/web/e2e/*.spec.ts`; `pgTAP` =
`supabase/pgtap`; `stack` = `scripts/e2e/security.test.mjs`; unit = Vitest.
